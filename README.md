# Astro Test Site

A minimal Persian Astro site prepared for free deployment on GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Deployment

The included GitHub Actions workflow builds and deploys the site on every push to `main`.

Expected URL: https://hameddd.github.io/astro-test-site/

## Custom domain

After GitHub Pages is enabled, add your domain under **Settings → Pages → Custom domain**, then point the domain DNS to GitHub Pages.
